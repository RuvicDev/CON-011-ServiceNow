1. ¿Qué es y para qué sirve?

ServiceNow permite gestionar incidentes ITSM. El conector crea, consulta, actualiza y comenta incidentes.

2. Prerrequisitos

Instancia ServiceNow Developer o de prueba, usuario con permisos sobre incident y acceso a Table API.

3. Configuración en ServiceNow

Crea o despierta una instancia developer y confirma usuario/contraseña.

4. Permisos requeridos

Leer, crear y actualizar registros incident; escribir comments/work_notes.

5. Configuración en Ruvic

Completa URL, usuario, contraseña y opciones.

6. Verificación

Ejecuta Probar conexión y crea un incidente de prueba.

7. Solución de problemas

401/403 indica credenciales/permisos; timeout al crear puede requerir skip_transaction en developer.

8. FAQ y seguridad

No compartas contraseñas. No se eliminan incidentes.
